# Lógica de Programação em Portugol

Repositório destinado ao registro dos meus estudos e práticas de **Lógica de Programação**, utilizando a linguagem Portugol.

# Conteúdos estudados

Os exercícios estão organizados de acordo com os principais conceitos de lógica de programação:

- **Introdução à programação**
  - Variáveis e constantes
  - Entrada e saída de dados
  - Operadores aritméticos, relacionais e lógicos

- **Estruturas condicionais**
  - Estruturas `se` e `senão`
  - Condicionais simples e aninhadas

- **Estruturas de repetição**
  - `para`
  - `enquanto`
  - `repita`
  - Variáveis contadoras
  - Flags e controle de repetição

- **Vetores**
  - Declaração e inicialização de vetores
  - Acesso e manipulação de elementos
  - Percorrimento de vetores utilizando estruturas de repetição
  - Armazenamento e processamento de dados

- **Operações e cálculos**
  - Operações matemáticas
  - Média e porcentagem
  - Resolução de problemas utilizando algoritmos

# Objetivo

Desenvolver o raciocínio lógico e compreender os fundamentos da programação, criando uma base para o aprendizado de outras linguagens.
